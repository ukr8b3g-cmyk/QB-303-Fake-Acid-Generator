LET'S GO で再生。AUTO MODE は最初から ON。ドラムの16ステップ1周目はベースが休み、2周目で鳴り、以後繰り返します。最初は控えめで、CHAOS や各ボタンで変化を増やせます。BASS RAND は4周ごとに新しいベースを作ります。AUTO MODE をオフにすると、再生ボタンの隣の BASS で手動操作できます。

HOOK AUTO は短いメロディーの ON/OFF を兼ね、AUTO MODE 中は10種類から自動で選びます。SYNTH ボタンは3種類のシンセアレンジを切り替えます。RUSH は次の小節から4小節で加速し、GO MAD! はスクラッチ風の音を入れます。INCREASE ACID は4小節かけて音色を強めます。

SAVE WAV は現在のベース、ドラム、HOOK、SYNTH ARRANGE、VOX と音色を4小節の WAV に書き出します。AUTO MODE の演奏を録音する機能ではありません。設定はこのブラウザに自動保存されます。

ノブは上下ドラッグと矢印キーで操作でき、ダブルクリックで初期値に戻ります。TB-303 の完全再現ではない独立した音遊びです。
