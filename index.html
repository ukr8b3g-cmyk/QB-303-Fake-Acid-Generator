あそびかた / ABOUT THIS TOY

LET'S GO で再生。下のドラム16ステップが1周すると1小節です。AUTO MODE は最初から ON。ベースは最初の1周だけ休み、その後は4周鳴って2周休む流れを基本に、ときどき4周休む間奏が入ります。音色の自動変化は控えめで、スクラッチは自動では鳴りません。BASS RAND は4周ごとに新しいベースを作ります。AUTO MODE をオフにすると、再生ボタンの隣の BASS で手動操作できます。

HOOK AUTO は短いメロディーの ON/OFF を兼ね、AUTO MODE 中は10種類から自動で選びます。SYNTH ボタンは3種類のシンセアレンジを切り替えます。RUSH は次の小節から4小節で加速し、GO MAD! はスクラッチ風の音を入れます。BEAT GACHA はキック・ハット・クラップの16ステップを押すたびに作り直します。再生中は次の小節から鳴ります。

ANIMAL VOICE と SFX PAD は押したときだけ鳴ります。動物・人声風の10種類と、急ブレーキを含む効果音10種類から選ばれます。SFX の最初の一押しは急ブレーキです。どれも録音ではなく簡易合成音です。

SAVE WAV は現在のベース、ドラム、HOOK、SYNTH ARRANGE、VOX と音色を4小節の WAV に書き出します。AUTO MODE や手押しパッドの演奏を録音する機能ではありません。設定はこのブラウザに自動保存されます。

ノブは上下ドラッグと矢印キーで操作でき、ダブルクリックで初期値に戻ります。TB-303 の完全再現ではない独立した音遊びです。
